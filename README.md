Gemelon Studios' portfolio site.
To add a featured project: one entry in featured.json + a 1440x900 WebP in assets/.
Optional fields: `caption` (viewer caption for the main image), `status` (short muted label, e.g. for projects with no public link) and
`gallery` (a list of `{ "src", "caption" }` 1440x900 WebPs, opened from a Screenshots button).
To add an open-source project: tag the repo with the `portfolio` topic on GitHub.
